Ionic + React cross-platform mobile app for **Speech To Text**.

Part of [Chaowalit Greepoke](https://bookchaowalit.com)'s 101 Portfolio Projects.

## Tech Stack

- **Framework:** Ionic 8 + React 18
- **Language:** TypeScript
- **Build Tool:** Vite
- **UI:** Ionic Components + Ionicons

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
# Static web build in dist/. A native app would need a Capacitor project, which does not exist yet.
```
